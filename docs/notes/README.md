# OpenHarness Notes

`docs/notes/`는 OpenHarness를 공부하면서 만든 보조 문서 모음이다.

- GitHub에서 바로 읽을 때는 `Markdown` 버전을 먼저 본다.
- 원래 레이아웃과 스타일이 필요한 경우에는 같은 이름의 `HTML` 원본을 연다.
- `assets/` 아래의 `svg` 파일은 `Markdown`에서 다이어그램이 바로 보이도록 분리한 이미지다.
